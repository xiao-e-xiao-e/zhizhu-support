# Atlas 2.0：支持工单与服务时限

本文件是虚构演示产品的服务政策，供测试使用。

## 提交内容

标题简要描述现象；描述包含产品版本、复现步骤、报错信息和已经尝试的方法。可以附上自己的相关对话，附上的内容会作为工单快照供客服阅读。不要提供密码或 API 密钥。

## 状态和角色

流程为新建、处理中、已解决、已关闭。客服接单、回复并填写解决说明，提交者确认问题解决后关闭；已解决的问题仍未恢复时可以重新打开。普通用户只能查看本人提交的工单。

## 首次响应承诺

Atlas 2.0 的高优先级工单在 4 小时内首次响应，普通工单在 24 小时内首次响应。首次响应不等于最终解决时间。紧急程度以业务影响判断，不要因重复提交同一问题提升优先级。

## 智能助手建单

助手只能准备工单草稿。用户核对标题、描述、优先级和产品版本，再点击确认提交。没有确认前，不会创建正式工单。
