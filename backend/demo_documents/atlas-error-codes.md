# Atlas 2.0：常见问题速查

以下 E 前缀代号属于虚构演示产品的诊断场景，不是当前后端完整的错误码定义。

## E401：登录会话过期

退出账号后重新登录。仍然失败时记录时间、浏览器、产品版本和复现步骤，再提交工单。不要修改模型 API 密钥来解决用户登录问题。

## E413：文件超限

Atlas 2.0 单文件不得超过 20 MB。拆分或压缩后重新上传，检查文档是否包含大量重复图片。不要套用 3.0 的 50 MB 演示规则。

## 无可用文本

扫描件应先 OCR，空文件应补充正文，损坏或加密文件应导出为正常格式。修改文件后重新入库；仅仅重试并不会修复原件内容。

## 找不到答案

检查是否选错产品或版本、文档是否已经发布、相似度阈值是否过高。没有资料支持时应明确说明信息不足，收集细节或转人工，不编造价格、支付方式和承诺。
