# Atlas 2.0：账号、登录与密码重置

本文件为虚构的演示产品资料，用于测试知识检索、版本隔离和客服流程，不构成实际服务承诺。

## E401 登录会话过期

Atlas 2.0 的 E401 表示登录会话过期。先退出账号，再重新登录，不需要修改模型 API 密钥。仍无法登录时，记录出现时间、浏览器版本和错误提示，提交支持工单。不要在工单中填写密码、验证码或 API 密钥。

## 找回密码

密码重置链接有效期为 30 分钟，且只能使用一次。链接过期后重新申请，使用最新邮件中的链接；连续申请时旧链接会失效。密码建议至少 12 位，包含字母、数字和符号。

## 权限说明

普通用户可提问、查看自己的对话和工单；客服可维护资料和处理团队工单；管理员可管理账号、审核发布知识。管理员也不能默认读取其他用户的私人对话。没有账号时联系团队管理员，不开放公共注册。
