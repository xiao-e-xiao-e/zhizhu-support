# 知助 · 智能客服与知识协作平台

知助（ZhiZhu Support）面向软件产品团队，提供产品知识检索、智能对话、工单协作和 FAQ 知识运营。

## 用户流程

1. 管理员维护产品、版本、账号与资料权限。
2. 客服上传资料，由独立后台任务解析、分块并生成本地语义向量。
3. 管理员核对修订并发布；只有已发布且属于用户授权范围的内容进入检索。
4. 用户在统一助手中自然提问，正文流式显示，可点击引用查看资料片段。
5. 需要人工支持时，助手整理工单草稿，由用户核对后确认提交。
6. 客服跟进处理，整理可复用 FAQ，经审核入库并发布。

## 技术实现

前端使用 Vue 3、TypeScript、Vite、Element Plus 和 Pinia；后端使用 FastAPI、SQLAlchemy 与 Alembic。业务数据库支持 PostgreSQL 和 SQLite；Chroma 服务配合 BGE 中文嵌入完成语义检索，模型 API 负责工具选择和回答生成。

## 数据边界

会话属于个人；工单按本人或客服团队范围访问；产品资料受账号授权、版本和发布状态限制。模型不能改变服务端身份权限，也不能跳过工单确认步骤。

本文件用于介绍项目，可按正常入库流程作为资料使用，不代表具体软件产品的操作政策。
